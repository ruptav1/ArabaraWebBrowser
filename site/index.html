ARABARA

PERSONAL WEB TERMINAL // HTTPS ONLY // NO SEARCH

ARABARA IS NOT MADE FOR MULTITASKING, RESEARCH OR SEARCHING THE WEB. IT EXISTS FOR ONE JOB: RUNNING WEBSITES AS LIGHT AND AS STABLE AS POSSIBLE WHILE YOU ARE GAMING.

PASTE A LINK.
OR TYPE THE DOMAIN.

There is no search box. Type the address you want, for example youtube.com, discord.com or music.youtube.com, or paste a link you copied. Need to look something up? Type google.com and search there.

REQUIRED

Windows 11, any version, or Windows 10 version 1607 (build 14393) or newer. 64-bit Windows only.
Tested on Windows 11 Pro, build 26200.

A 64-bit (x64) Intel or AMD processor. Windows on ARM is not tested.

.NET Framework 4.8 or 4.8.1. Included with Windows 10 version 1903 and newer and with Windows 11; earlier Windows 10 versions need the free installer from Microsoft.

Microsoft Edge WebView2 Runtime (Evergreen), version 154.0.4258 or newer. Tested with 154.0.4258.62; built with the WebView2 SDK 1.0.4258.31. The runtime is part of Windows 11 and updates itself; on Windows 10 it can be installed from Microsoft.

Memory: 4 GB of RAM at least, 8 GB recommended. Arabara itself uses about 100 MB; each website adds its own, and the music player adds about 150 to 250 MB while it plays and gives it back a minute after it stops. Tabs left in the background release their memory after a minute.

Disk: 2 MB for the program. History, sign-ins and settings are kept in %LOCALAPPDATA%\Arabara and grow with use.

Display: a window of at least 800 x 480; 1280 x 720 or larger recommended. High-DPI screens are supported.

Network: an internet connection. Arabara opens HTTPS addresses only. Twice a day it asks GitHub whether a newer version is out; when one is, UPDATE appears in the toolbar and installs it after you confirm.

FOR SOME FEATURES

Music: a YouTube Music account, free or Premium, signed in once at music.youtube.com inside Arabara.

SOUND WAVE background: an active audio output device; it follows what that device plays.

RINGS background: moves with the music terminal's music. On Windows 11 it hears only Arabara's own sound, so games and other apps never move it; on Windows 10 it follows what the output device plays.

Ad blocking: uBlock Origin Lite (free), not included in the download. Get uBOLite_<version>.edge.zip from its GitHub releases and extract it into %LOCALAPPDATA%\Arabara\extensions\ublock-lite (the folder that holds manifest.json), then start Arabara.

Discord tab streaming: Discord open in an Arabara tab.

FIRST RUN

Arabara is not code-signed yet, so Windows may show "Windows protected your PC". Choose More info, then Run anyway.
